# Majdoubi Maram - Portfolio

A responsive personal portfolio for Majdoubi Maram, Data Scientist exploring AI and practical data-driven solutions.

## Open locally

Open index.html in a browser. The site uses plain HTML, CSS, and TypeScript source with a browser-ready JavaScript file, plus local images and a downloadable CV. Google Fonts are loaded from Google Fonts when internet access is available.

## Contents

- Profile, projects, technical stack, certifications, publications, and contact form.
- Project presentation images and certificate scans.
- assets/Majdoubi-Maram-CV.pdf is the downloadable two-page CV.
- main.ts is the TypeScript source for lightweight interactions; main.js runs directly in the browser.

## Motion effects

The portfolio uses GSAP for entrance and scroll-reveal motion, and Vanilla Tilt for restrained pointer-based 3D depth on project and certificate cards. Both libraries load from pinned jsDelivr versions. Effects are disabled when reduced motion is requested, and tilt stays off on touch-oriented layouts.
